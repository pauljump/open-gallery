# Why Open Gallery

Galleries and artists make the work, the catalog and the relationships. The software that holds them should give the gallery lasting control.

Open Gallery is the software a gallery runs on: its inventory, consignments, exhibitions and public catalog. It works alongside whatever marketplaces and websites the gallery already uses, and keeps the gallery's catalog portable.

| Promise | What makes it true in this release |
|---|---|
| Free to run | No license fee, subscription, commission or paid AI call in any core task. |
| Free to change | AGPL-3.0 source. Look, fields and layout change through settings and a custom CSS file kept in your data folder, so updates do not erase them and no private fork is needed. |
| Free to leave | One export holds every original image, record, relationship, setting and import file, with checksums; restore is tested into a fresh install. Spreadsheets inside open without Open Gallery. |
| Keep your marketplaces | Imports work from a copy of your sheet. Artsy, Artnet and website links stay on each work. Nothing is written to any outside system. |
| You choose what is public | Works start private. Location, costs, consignors, buyers, notes and unknown columns can never be published; this is tested on every build. |
| Keeps working | Runs on your computer with no account or server of ours. The public catalog is plain files any host can serve. |
