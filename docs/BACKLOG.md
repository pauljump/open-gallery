# Prioritized backlog after 0.1

1. **Pilot with one real gallery** (with permission): time the first import, count corrections, record where they get stuck. Nothing below outranks this.
2. **Publish the repository and tag 0.1.0**, then test the install prompt separately in Claude and in Codex.
3. **Screen reader pass** (VoiceOver, NVDA) and a Windows run.
4. **Remember "skip" decisions** for duplicate rows so the same sheet does not ask again.
5. **One-click upload of the public catalog** to a host the gallery chooses, with the cost shown first.
6. **Edition parents and physical units**: today an edition is a text field on one record.
7. **Contacts and inquiries** stored privately, with one note per collector, never published.
8. **Optional local AI** (off by default, owner-configured, e.g. Ollama): describe images, draft captions, suggest column mappings. Must never fall back to a paid service and must be benchmarked for correctness first.
9. **Artsy partner access**: if Artsy grants access, start read-only, match external ids, dry-run differences, pilot a handful of works. Until then, file exchange only.
10. **Shared, opt-in discovery**: an association-run index that reads galleries' `catalog.json` feeds and honours withdrawals.
11. **ZIP64** for exports over 4 GB; incremental exports.
12. **Multi-user office server**: authentication, concurrent edits, scheduled backups.
